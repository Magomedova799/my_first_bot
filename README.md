# my_first_bot
Простой telegram бот для управления задачами.

Функции:
1. Добавление задачи
2. Просмотр задач
3. Отменить задачу выполненной
4. Удалить задачу
5. Статистика задач

Команды:
1. /add - добавить задачу
2. /tasks - показать задачу
3. /done - отметить задачу выполненной
4. /delete - удалить задачу
5. /stats - статистика задач

Используется также библиотеки aiogram и FSM.
